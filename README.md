# سجلات الطلاب PWA

تطبيق عربي محلي لإدارة سجلات الطلاب والتقييمات والحضور وجدول المعلم، مع واجهة محسنة لـ iPhone وSafari ودعم العمل كتطبيق PWA.

## الإصدار الحالي

**v4.18.2 — Weekend School-Day Fix**

ينظم هذا الإصدار التقييمات في أرشيف شهري قابل للطي مع بحث وفلترة حسب النوع والفترة وحالة اكتمال الرصد، دون تغيير بيانات الدرجات أو نموذج التخزين.

## الوظائف الرئيسية

- تقييمات زمنية ودرجات مستقلة لكل نشاط.
- حضور يومي وتقارير شهرية وفصلية.
- إدارة الفصول والطلاب واستيراد CSV.
- جداول متعددة للمعلم مع فترات سريان ومناوبة وإشراف.
- تقارير A4 وحفظ PDF.
- حفظ محلي في IndexedDB مع fallback إلى localStorage.
- نسخ احتياطي واستعادة JSON.
- PWA يعمل دون اتصال بعد التحميل الأول.

## بنية المشروع

- `index.html` — هيكل الواجهة والنوافذ.
- `app.js` — حالة التطبيق ومنطق التقييمات والحضور والجداول والتقارير.
- `styles.css` — أنماط الشاشة والاستجابة للجوال.
- `print.css` — تنسيقات الطباعة وA4.
- `sw.js` — التخزين المؤقت والتحديث التلقائي.
- `version.js` — رقم الإصدار المنشور.
- `scripts/validate.cjs` — فحص جودة بدون مكتبات خارجية.

## فحص الجودة

```bash
npm run validate
```

يتحقق الفحص من سلامة JavaScript، وتطابق رقم الإصدار، وعدم تكرار معرفات HTML، ووجود ملفات PWA المحلية، ومنع أخطاء selectors المتكررة.

## الخصوصية

لا توجد قاعدة بيانات خارجية في هذه النسخة. سجلات الطلاب محفوظة على جهاز المستخدم. يوصى بإنشاء نسخة احتياطية JSON دوريًا لأن حذف بيانات المتصفح قد يحذف التخزين المحلي.
