# سجلات الطلاب PWA — V3.3

تطبيق عربي يعمل محليًا لإدارة سجلات الطلاب من الهاتف أو الحاسب، مع تركيز على iPhone وSafari.

## الجديد في V3.3

- عند نقل طالب إلى فصل آخر يُدرج تلقائيًا في موضعه الأبجدي داخل الفصل الجديد باستخدام ترتيب عربي.
- تم منع بطاقات التقييم وعناوينها من توسيع الصفحة على الجوال؛ النصوص الطويلة تلتف داخل البطاقة وتبقى شاشة التقييمات ضمن عرض الجهاز.
- دفتر الدرجات نفسه يبقى داخل حاوية تمرير أفقية عند الحاجة، دون تشويه عرض التطبيق بالكامل.
- طباعة تقرير الفصل أصبحت كشف متابعة رسمي النمط مستقلًا عن شاشة التحليل، بحجم A4 أفقي.
- كشف الفصل يتضمن: رقم الطالب، الاسم، الواجبات، المشاركة والتفاعل، المشاريع والبحوث، التطبيقات العملية، الاختبارات القصيرة، الاختبارات، المجموع المرصود، النسبة، والغياب.
- رأس الكليشة الرسمية وجدول الأعمدة موضوعان داخل `thead` ليعاد ظهورهما تلقائيًا عند امتداد الكشف إلى أكثر من صفحة في الطباعة.
- تظل مؤشرات التحليل والتنبيهات داخل التطبيق ولا تزاحم الورقة الرسمية المطبوعة.
- Cache الإصدار الحالي: `student-roster-pwa-v3.3`.

## تحسينات V3.2

- نافذة إنشاء وتعديل التقييم Mobile-first على شاشة الجوال، وتستخدم كامل ارتفاع الشاشة مع احترام Safe Area في iPhone.
- حقول التقييم عمودية على الجوال، بحجم لمس مناسب وخط 16px لتجنب التكبير التلقائي في Safari.
- أزرار الحفظ والإلغاء ثابتة أسفل نافذة التقييم لتبقى ظاهرة أثناء التمرير.
- تقرير الطالب يطبع على A4 عمودي.
- تقرير الفصل يطبع على A4 أفقي.
- كليشة مدرسية رسمية النمط تتضمن: المملكة العربية السعودية، وزارة التعليم، إدارة التعليم/المنطقة، المدرسة، المادة، العام الدراسي، الفصل الدراسي، الصف، الفصل، معلم المادة، وعنوان التقرير.
- تقرير الطالب يتضمن اسم الطالب في رأس الكليشة وتوقيع معلم المادة ومدير المدرسة في نهاية التقرير.

## وظائف V3 الأساسية

- سجل تقييمات زمني بدل خانات ثابتة.
- كل تقييم يحتوي اسمًا، نوعًا، تاريخًا، درجة عظمى، ووصفًا اختياريًا.
- دفتر درجات مستقل لكل تقييم.
- ترحيل تلقائي لبيانات V1/V2 دون اختلاق تواريخ للبيانات القديمة.
- تقارير شهرية أو للفصل كاملًا.
- مؤشرات أداء واكتمال رصد منفصلة.
- تنبيه قابل للضبط للطلاب الذين ينخفض أداؤهم أو يتكرر غيابهم.
- رسم زمني لتطور مستوى الطالب.
- سجل حضور يومي وحصيلة شهرية.
- تقرير فردي قابل للطباعة.
- استيراد CSV وتصدير CSV ونسخة احتياطية JSON.
- الاستيراد المدرسي الجماعي يتعرف على أعمدة `الصف` و`الفصل` و`الاسم`، وينشئ الفصول تلقائيًا ويوزع كل طالب على فصله الصحيح مع الحفاظ على السجلات السابقة للطالب المطابق بالاسم.
- إدارة الطلاب: إضافة، تعديل الاسم، ترتيب، نقل، حذف.
- IndexedDB مع fallback إلى localStorage.
- Service Worker للعمل دون اتصال بعد أول تحميل ناجح عبر HTTPS.

## الخصوصية

لا توجد قاعدة بيانات خارجية في هذه النسخة. السجلات تحفظ على الجهاز. استخدم النسخة الاحتياطية JSON دوريًا لأن حذف بيانات المتصفح قد يحذف السجل المحلي.

## التشغيل

انشر المجلد عبر HTTPS، مثل GitHub Pages. لا تعتمد على فتح `index.html` مباشرة من Files لأن Service Worker يتطلب سياقًا آمنًا.
