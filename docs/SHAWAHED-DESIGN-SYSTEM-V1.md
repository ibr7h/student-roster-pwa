# شواهد — Design System v1 (فرع مراجعة، 28 أكتوبر 2026)

## الغرض
طبقة موحدة لتصميم واجهة PWA، وفق مبادئ Apple HIG وMaterial Design 3، دون إعادة إنشاء الشاشات أو تعطيل سير العمل القائم.

## الهوية
- اللون المؤسسي للترويسة: #0d4153.
- اللون التفاعلي الأساسي: #0e6875؛ التركيز: #0b7681؛ النص: #18364e؛ الخلفية: #f5f8fb.
- تباعد 4/8/12/16/20/24/32/40px (8pt أساس و4pt للتفاصيل).
- خطوط نظام عربية احتياطية دون جلب خطوط خارجية.
- أزرار بحد أدنى 48px في المكونات الجديدة، مع حالات ثانوية/خطرة/تعطيل/تحميل.
- مؤثرات انتقال قصيرة ووظيفية، مع احترام prefers-reduced-motion.
- Skeleton reusable للحالات المرتبطة بجلب بيانات فعلي؛ لا يقدّم انتظارًا مزيفًا.
- RTL عبر التخطيطات الحالية وبدون تغيير اتجاه النماذج أو تحريك التقرير A4.

## التوافق والسلامة
- لا مساس بـ API، هويات المستخدمين، الصلاحيات، تخزين الملفات أو ترخيص المدرسة.
- تظل معالجة status bar على iPhone ثابتة وغير شفافة.
- تظل هندسة أربعة أزرار للتنقل السفلي وشكلها باللون المدرسي كما في r27.
- لا مساس بـ CSS الطباعة أو محتوى PDF وQR والشواهد.
- يتم إدراج ملف التصميم بعد كافة ترقيعات v3.9 وبحفظه في Service Worker.
- مؤشرات الانتظار الحالية للمزامنة تتضمن aria-busy، ولا توهم بوجود طابور حفظ دون إنترنت.

## حدود المرحلة الحالية
المكتبة الجديدة متاحة لتوحيد الشاشات تدريجياً؛ إظهار Skeleton في كل قائمة يتطلب ربطه بحالات Fetch الحقيقية لكل شاشة، وهذا غير مفعل عشوائياً حفاظاً على البيانات والتجربة.
إيماءات السحب والضغط المطول لا تُفرض على العناصر الحساسة قبل إضافة بديل واضح واختبار تعارضها مع Scroll وVoiceOver.

## بوابات الدمج
1. CI: تجميع static PWA، التحقق من الاستيراد، الكاش، الألوان، accessibility وbusy state.
2. اختبار WebKit / iPhone: شريط الحالة، التنقل السفلي، العربية، منطقة الأمان، دون zoom عرضي.
3. مسارات المدير والفريق، النوافذ السفلية، التحميل/الفشل، الاختبارات الأفقية للشواهد.
4. طباعة PDF A4 وQR مع تطابق المعاينة ومراجعة حفظ التقرير.
5. الموافقة على دمج نسخة المعاينة قبل الإنتاج، ونسخة استعادة معروفة.
